# Instructions

Step-by-step use of the vault. Start from [[Home]]; deeper rules are in [[Vault-Guide]].

## 1. Create a note
1. Press `Ctrl+N`: the note lands in `00_Inbox/`.
2. Insert a template: `Ctrl+P` > *Templates: Insert template*, then pick one:

| Need | Template | Goes to |
|---|---|---|
| Daily log | [[Daily]] | `01_Daily/` |
| Outcome with an end date | [[Project]] | `02_Projects/` |
| Single idea or fact | [[Note]] | `04_Resources/Reference/` |
| Meeting | [[Meeting]] | `02_Projects/` or area |
| Sales lead | [[Sales-Lead]] | `03_Areas/Sales/` |
| Reusable prompt | [[Prompt]] | `04_Resources/Prompts/` |
| Choice with reasons | [[Decision]] | project or area |
| New hub page | [[Area-Hub]] | `03_Areas/` |

3. Fill the properties, add `[[links]]`, move the note out of the inbox.

## 2. Daily routine
- Open today's note (*Daily notes* button), set focus tasks, log as you go.
- Check [[Home]] for active projects.

## 3. Weekly (15 min)
- Triage `00_Inbox/`: properties, tags, links, move. Rules: [[Tagging-and-Naming]].
- Archive finished work to `05_Archive/`.

## 4. Areas
- Sales: [[Sales-Research-Hub]] (raw files in `sales research/`)
- AI and prompts: [[AI-Workflows-Hub]]

## 5. Working with Claude
Say what you want in plain language; Claude follows [[CLAUDE]] and [[Claude-Workflow]].

## 6. Formats
Properties, links, callouts, tasks, canvas and queries are all defined in [[Obsidian-Formats]].
